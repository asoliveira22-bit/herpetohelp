# Changelog

All notable public changes to HerpetoHelp are documented in this file. The project
uses semantic versioning for public releases.

## [1.0.0] - 2026-09-05

First stable public release.

### Added

- Interactive map for Brazilian amphibian and reptile occurrence records.
- Multi-species search, comparison, visibility, and display controls.
- KMZ polygon processing and spatial filtering in the browser.
- Spreadsheet export with summary and occurrence-provenance worksheets.
- Brazilian biome visualization and biome-based species analysis.
- Compact per-species files and a binary spatial index for efficient loading.
- Information panel with data provenance, limitations, privacy, and citation guidance.
- HerpetoHelp visual identity and browser favicon.

### Data snapshot

- SALVE/ICMBio snapshot identified in the application: 2026-08-13.
- Biome boundaries identified in the application: IBGE, Biomas do Brasil 2025.
